# 🌦️ Mumbai Weather Forecasting & Safe Route Navigation App

## 📌 About

This project is a **weather forecasting application** built specifically for the **Mumbai region**, using historical weather data from **1960 to 2023**.
It combines **machine learning–based weather prediction** with a **Flutter-powered mobile interface**, offering users both accurate forecasts and enhanced travel safety.

A unique feature of this application is the **Safe Route Navigation System**, which analyzes weather conditions and suggests the **safest possible travel route** during adverse weather events.

## 🚀 Features

* **Weather Forecasting**

  * Predicts weather conditions using historical data (1960–2023)
  * Python-based backend with trained ML models
* **Real-time UI**

  * Beautiful and responsive Flutter frontend
* **Safe Route Navigation**

  * Suggests the safest travel routes during heavy rain, storms, or flooding
  * Takes into account real-time weather parameters
* **Location-based insights**

  * User-friendly map interface
  * Easy-to-understand weather visuals
